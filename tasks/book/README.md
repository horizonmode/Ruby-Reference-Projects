# Book Library

An interactive library that manages books, checkout state, returns, and
checkout history.

## Topics included

- Classes and object composition
- Constructors with positional and keyword arguments
- Attribute readers and writers
- Boolean predicate methods
- Encapsulating state changes in methods
- Arrays and hashes
- Hash default blocks
- Searching collections with `find`
- Filtering collections with `select`
- Iteration with `each`
- Symbol-to-Proc shorthand such as `select(&:checked_out?)`
- Case-insensitive string comparison
- Recording timestamps with `Time`
- Conditional branching
- Interactive command-line input and loop control
- Splitting classes across files with `require_relative`

## Run

From the repository root:

```bash
ruby tasks/book/main.rb
```
