# Tournament

A combat tournament in which different fighter types battle using inherited,
mixed-in, overridden, and dynamically attached behaviour.

## Topics included

- Classes and inheritance
- Calling parent implementations with `super`
- Polymorphism through a shared fighter interface
- Modules and mixins with `include`
- Adding behaviour to one object through its singleton class
- Method overriding
- Public and private method visibility
- Template-method-style customization
- Attribute readers and writers
- State management across repeated battles
- Randomized behaviour
- Probability-based rules
- Array shuffling and pairing with `each_slice`
- Destructuring block parameters
- Conditional expressions and guard clauses
- Numeric bounds with `min` and `max`
- Loading related files with `require_relative`

## Run

From the repository root:

```bash
ruby tasks/tournament/main.rb
```
